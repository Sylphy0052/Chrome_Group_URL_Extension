# Tab URL Exporter

現在のウィンドウで開いているタブのURL一覧を、テキストファイル (.txt) としてダウンロードするChrome拡張機能です。

拡張アイコンをクリックするだけで、ポップアップも確認ダイアログもなく、その場でファイルが保存されます。

## 特徴

- **ワンクリック**: アイコンをクリックした瞬間にダウンロードが始まります
- **並び順を保持**: タブの並び (左から右) をそのまま出力します
- **加工なし**: `chrome://` や `file://` を含め、開いているタブをそのまま記録します
- **オフライン動作**: 外部への通信は一切行いません

## インストール

Chrome ウェブストアには公開していないため、未パッケージ拡張機能として読み込みます。

1. このリポジトリを取得します

   ```bash
   git clone https://github.com/Sylphy0052/Chrome_Group_URL_Extension.git
   ```

2. Chromeで `chrome://extensions` を開きます
3. 右上の**デベロッパーモード**をオンにします
4. **「パッケージ化されていない拡張機能を読み込む」**をクリックします
5. 手順1で取得したディレクトリ (`manifest.json` があるディレクトリ) を選択します
6. ツールバーのパズルアイコンから、拡張機能をピン留めしておくと使いやすくなります

## 使い方

### 基本の手順

1. URLを書き出したいタブが開いているウィンドウをアクティブにします
2. ツールバーの拡張アイコンをクリックします
3. ダウンロードフォルダに `tabs-YYYYMMDD-hhmmss.txt` が保存されます

保存先を毎回選ぶダイアログは表示されません。Chromeの設定で「ダウンロード前に各ファイルの保存場所を確認する」をオンにしている場合のみ、ダイアログが表示されます。

### 出力されるファイル

- ファイル名: `tabs-YYYYMMDD-hhmmss.txt` (実行時のローカル時刻)
- 文字コード: UTF-8
- 形式: 1行に1URL、末尾に改行あり

```
https://example.com/a
https://example.com/b
chrome://extensions
```

### 実行結果の確認

処理結果はアイコンのバッジに2秒間表示されます。

- `OK` (緑): ダウンロードに成功しました
- `0` (グレー): 出力対象のURLが0件でした
- `ERR` (赤): エラーが発生しました。`chrome://extensions` の「Service Worker」からコンソールを確認してください

### 対象範囲

**アクティブなウィンドウの全タブ**が対象です。

- 別のウィンドウのタブは含まれません。ウィンドウごとに実行してください
- タブグループに属していないタブも含め、そのウィンドウの全タブを出力します
- 非表示のタブ (タブグループを折りたたんでいる場合など) も出力されます
- シークレットウィンドウで使う場合は、`chrome://extensions` の拡張機能の詳細から「シークレット モードでの実行を許可する」を有効にしてください

### 書き出したURLの再オープン

出力は1行1URLのプレーンテキストなので、他のツールにそのまま渡せます。

```bash
# 例: すべてのURLをChromeで開き直す
xargs -a tabs-20260813-162245.txt google-chrome
```

## 権限

| 権限 | 用途 |
| --- | --- |
| `tabs` | タブのURLを取得するために必要です |
| `downloads` | 生成したテキストファイルを保存するために必要です |

取得したURLはファイルの生成にのみ使用し、外部への送信・保存は行いません。

## 構成

```
manifest.json   拡張機能の定義 (Manifest V3)
background.js   アイコンのクリックを受けてURLを収集・ダウンロードするService Worker
icons/          拡張アイコン (16/32/48/128px)
```
